## Closely Spaced Trps in Human Proteins

This repository contains the code, input and output data for the paper "Uncovering Closely Spaced Tryptophan Residues in Human Proteins and Revealing Hidden Rules in Protein Folding and Function" by Duy Anh Vu, Md Rownak Abtahee Diganta, Manthan Desai, Aryaman Bahuguna and Bingyun Sun.
